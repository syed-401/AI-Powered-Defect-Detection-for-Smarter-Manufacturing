

## Overview
This project explores the use of computer vision and deep learning to classify manufacturing product images into two categories: **Defective** and **Non-Defective**.

## Objectives
- Prepare and preprocess manufacturing product images.
- Explore a Convolutional Neural Network (CNN) for image classification.
- Evaluate the model using suitable classification metrics.
- Document the methodology, findings, and limitations.

## Technologies
- Python
- PyTorch or TensorFlow
- OpenCV
- NumPy and Matplotlib
- scikit-learn

## Project Scope
The initial scope is binary image classification. Defect localization, identification of multiple defect types, and real-time industrial inspection are outside the initial scope.

## Project Status
Implementation and evaluation are in progress. Results will be documented after the corresponding experiments have been completed.

## Repository
This repository contains the project documentation and implementation files as they become available.
